# Embedded Linux Cross-Compilation

This repository contains tasks related to embedded Linux cross-compilation, kernel modification, and system building.

## Tasks

*   **[Task 1: Cross-Compiler and ARM Emulator with QEMU](Task1.md)**
    *   Setup and testing of an ARM cross-compiler and QEMU emulator.
*   **[Task 2: Building a Cross-Compilation Toolchain](Task2.md)**
    *   Building a custom cross-compilation toolchain using Crosstool-NG for Raspberry Pi 3.
*   **[Task 3: Adding a System Call to the Linux Kernel](Task3.md)**
    *   Adding a custom "Hello World" system call to the Linux kernel.
*   **[Task 4: Adding a 'Hello World' Module to the Linux Kernel](Task4.md)**
    *   Creating, compiling, and loading a simple kernel module.
*   **[Task 5: Creating a Minimal Linux System for the BeagleBone Black with Buildroot](Task5.md)**
    *   Using Buildroot to create a minimal embedded Linux system for the BeagleBone Black.
